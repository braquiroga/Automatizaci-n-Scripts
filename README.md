Este repositorio contiene una serie de scripts que desarrollé para automatizar tareas, resolver problemas comunes y facilitar el trabajo técnico diario. Están orientados principalmente a soporte, administración de sistemas y pequeñas herramientas de uso general.

Sobre este proyecto Muchos de estos scripts surgieron como soluciones a necesidades reales en el entorno laboral. También los utilizo como espacio para seguir practicando y aprendiendo nuevas herramientas y lenguajes (PowerShell, Bash, Python, entre otros).
